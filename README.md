# Hey, I'm Diego

I'm a Computer Science student and full-stack developer building API-first platforms, real-time systems, music web apps, dashboards, automation tools, and academic software.

My main project is the **NSQKK ecosystem**, a multi-domain fan platform powered by a FastAPI backend and multiple static frontends. I like building things end to end: backend architecture, clean interfaces, data, maps, music tools, cloud deployment, and systems that actually ship.

## About Me

- Currently building and maintaining the **NSQKK / Nsqkcharts ecosystem**
- Interested in backend engineering, full-stack development, real-time systems, data visualization, and cloud platforms
- I work with Python, FastAPI, Flask, JavaScript, Java, C, Lua, PostgreSQL, Docker, Google Cloud, and Cloudflare
- I enjoy projects that mix APIs, music, maps, automation, dashboards, and useful product ideas

## Featured Projects

### NSQKK Ecosystem

Multi-domain fan platform around NSQK, evolved from a Flask + Jinja SSR app into an API-first architecture with one FastAPI backend powering multiple static frontends.

[nsqkk.com](https://nsqkk.com)

### Radio ATP

Automated web radio backend using Flask, PostgreSQL, SQLAlchemy, Liquidsoap, Icecast, Docker, and Google Cloud Storage/CDN to manage queues, current tracks, listeners, and daily broadcasts.

### Minetest / Luanti Realtime Dashboard

Realtime player position and inventory dashboard for a Minetest/Luanti server, built with a Lua mod, Flask API, PostgreSQL/PostGIS, JWT auth, Server-Sent Events, generated maps, and admin tools.

[LinkedIn Demo](https://www.linkedin.com/feed/update/urn:li:activity:7328810642621034496/?utm_source=share&utm_medium=member_desktop&rcm=ACoAAFILCaYBifkBLas1zAm5Qeiu0TnDRCsTA_E)

### IDF Times

Web app for checking upcoming RER, Metro, and Bus departures across Ile-de-France stations, using Flask, PostgreSQL, JWT auth, JavaScript, and the Ile-de-France Mobilites API.

### DSP Realtime Location

Realtime location sharing system with an Ionic/Angular mobile app, Flask API, PostgreSQL/PostGIS, JWT auth, live tracking, alerts, and geospatial data handling.

### Web Hospital

Hospital management web application with patient, doctor, appointment, and admin workflows, focused on clean CRUD flows and practical database-backed features.
